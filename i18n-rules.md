# Global Translation Rules

This file contains translation guidelines that apply to all content in this project.

## Brand Names

- Always keep "Jixo AI" untranslated
- Keep "GitHub", "Astro", "React" and other technology names unchanged

## Technical Terms

- Use standard technical terminology for the target language
- Keep code-related terms in English when appropriate
- Preserve all variable names, function names, and code examples

## Tone and Style

- Use professional, technical tone for documentation
- Be concise and clear
- Maintain consistency in terminology throughout translations

## Formatting

- Preserve all Markdown formatting
- Do not translate URLs
- Keep code blocks unchanged
- Maintain the same structure as the original

## Examples

**Good:**
- "Jixo AI 是一个开源项目" (Chinese)
- "Jixo AI is an open source project" (English)

**Bad:**
- "吉克索 AI 是一个开源项目" (Translating brand name)
