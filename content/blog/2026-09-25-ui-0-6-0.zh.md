jixoai-ui v0.6（2026-09-25，当前 0.6.0）收录 v0.5.1（2026-09-13）以来的 540 个提交：82 feat / 87 fix / 257 docs，其余为 test / chore / 重构与合并提交。三条主线是文档站 110 个组件页重做、样式体系从 tailwind 迁往 stylex、timeline 与 chart 两个组件族的重做与修复。没有带 ! 标记的破坏性变更，升级无迁移动作。

## 文档站：110 个组件页重做

每个组件页现在遵循同一副骨架：Usage 前置，逐轴机制表 / Universal props / API / Accessibility / Theming / See Also 依序而下。此前各页结构不一，读者换个页面就要重新找目录。统一之后，同类信息在任何一页的同一位置。

安装命令的位置也变了。每页第一张卡的头区右侧现在直接携带 TerminalCard，`npx jixoai-ui add <name>` 逐字可见；独立的 Install 卡片全部撤销，共 77 页完成迁移（71 页 DocsInstall 形态、5 页 SectionCard 形态与 1 页试点页）。命令仍可复制，文档骨架 lint 的逐字校验保持通过。本轮重做经三轮外部评审（4.5 → 8.5 CONDITIONAL GO），残留缺口已归档为后续任务。

## 样式体系迁移：tailwind 退出，stylex 接管

写入样式的位置从 tailwind 工具类迁到 stylex 原子，站点与组件同步迁移，迁移台账覆盖 157 个文件（116 个原子模块、41 张样式表）。对使用 `npx jixoai-ui add` 的读者，这意味着新拿到的组件文件不再依赖 tailwind 工具类，原子样式随组件文件一起落地。迁移经五轮外部评审（4.5 → 6.1 → 7.8 → 8.4 → 9.4 GO）。

残留有常驻门禁盯守。verify:tailwindless 以白名单方式跟踪工具类身份，当前白名单为 2 个文件、7 个身份、7 处出现，每一处都有书面豁免理由（启动画面的首屏内联样式），方向只降不升。

## chart：字号修复与自适应

chart 家族在八轴迁移后出现过一组症状：42 处字形被放大到 96px（7.38 倍）、条形出现滚动条、个别页字号异常。根因是组件默认值解析把 donut 的外径 96 回填给了 bar / sparkline / line 三个部件的尺寸槽。修复给六个默认值落点补上同一守卫，只有显式数字才会写入尺寸槽（[406f12a7](https://github.com/jixoai/ui/commit/406f12a7)）。

自适应是第二个修复。条形图按容器实测容量重排字形预算，任何宽度下不出现滚动条，字号始终留在密度档位；所有条形共享同一条起点线。浏览器实测 360 至 1500 全宽度档，溢出为 0、滚动条为 0（[da509b3c](https://github.com/jixoai/ui/commit/da509b3c)）。

## timeline：按 reui 标准重做

timeline 组件重做：进度渲染改为分数 svg-path；连接线与节点的搭接改为压入节点自身的墨带（joint-lap，评审 GO 9.1/10，[998f36fd](https://github.com/jixoai/ui/commit/998f36fd)）；结构描边与节点边框共用同一权重 token，设一处、点线同变；ring 形点保持永久空心。回归电池 36/36。

## boot-splash：新组件

新增 boot-splash，一个加载掩膜层。它遵守零 CSS 文件法则：元素样式全部内联，样式表词汇随 head 内联块下发，字体加载竞态在结构上不可能发生。五种插槽（logo / loading / title / subtitle / description）、三种退场（opacity-out / blur-out / none）、超时上限 4 秒。安装是一条命令。

```bash
npx jixoai-ui add boot-splash
```

## 其他变更

- CLI 的 `--overwrite` 等透传旗标此前被 item 过滤器静默丢弃，一个条目在一次运行中重复写文件时会卡在确认提示；现已逐字透传到每个子进程（[b0ace9cb](https://github.com/jixoai/ui/commit/b0ace9cb)）。
- input-otp 的槽位宽度显式化，默认 40×40，密度阶梯在任何容器成立；此前裸输入的内在宽度会把槽位撑到 167px（[79038f95](https://github.com/jixoai/ui/commit/79038f95)）。
- popover 修复 position-area 的 span 后缀反转。
- W2 批量修缮覆盖 press-button 语义 / anchor 与 external 法则 / dialog 闭合 / alert 可关闭 / ItemField 图标车道 / ItemSegmented 与 ItemStepper 适配器。
- scroll-run 在打印投影下规范化并冻结，打印输出与视口无关，verify:print 35/35。
- 显式属性体系（explicit-props）完成设计冻结，八轴统一语法（named / auto / 数字与 query()）的契约文档就位，实现属于后续版本。
