OpenTray v0.23.0 is out (2026-09-10). Two things changed for users: `create` accepts a URL where it used to require a command, and app icons are generated when you do not supply one.

## A URL instead of a command

`create --url` builds a tray app whose window opens at the address. The payload carries no PTY, no shell assets and no `node-pty` dependency, and the app id is derived from the address.

```bash
npx create-opentray create --url https://example.com
# https://example.com/app  ->  app id "app.com.example", name "App"
```

The address is known before anything runs, so creation fetches the page once and adopts its `<title>` and best favicon as defaults. Explicit flags always win. A failed fetch falls back silently to the address-derived name and a glyph icon, and `--no-scrape` turns the fetch off.

| | `--exec` app | `--url` app |
|---|---|---|
| what runs | your command, supervised over a PTY | nothing; the window opens at the address |
| identity | derived from runner and package | derived from the address |
| title and icon defaults | supplied by you | scraped from the page once |

Add `--toolbar` to wrap the page in an address bar with back, forward and reload buttons, plus the Cmd/Ctrl+arrows, Cmd/Ctrl+brackets, Cmd/Ctrl+R, F5 and Cmd/Ctrl+L shortcuts while focus is inside it. Pages that forbid embedding cannot be wrapped: creation reads the response headers (`X-Frame-Options` and CSP `frame-ancestors`) during the scrape, and when the site refuses it prints a notice and falls back to a direct window. Every URL app gets Reload in its tray menu either way.

## App icons, generated

When `appIcon` is omitted, the runtime synthesizes a first-letter glyph icon from the app name into the macOS bundle and caches it under the runtime directory, so the Dock stops showing the generic executable placeholder. `appBundle.defaultAppIcon: false` restores the previous behavior, and an explicit `appIcon` always wins.

```ts
await createTray({ /* tray icon and menu */ }, {
  appId: "com.example.build",
  appName: "Build",
  appBundle: { defaultAppIcon: false },   // opt out of the synthesized icon
});
```

The generation kernel now lives in one package, `@opentray/icon`: glyph defaults, composition, squircle tiling and ICNS/ICO/Linux PNG encoding on a WebAssembly image stack (jsquash decodes and resizes, resvg renders SVG), with no sharp and no libvips anywhere. `@opentray/vite-plugin` calls the same kernel and keeps its public API.

In the wizard's URL mode the two icons a macOS app needs are handled separately. App icon candidates are the originals plus an AI-extracted subject; the tray icon uses solid silhouettes, which is what the macOS tray template expects. Extraction runs in the browser, with the model served through a proxy on the wizard server backed by a persistent on-disk cache: the model downloads from the CDN once and every later session, on any random port, serves it from loopback. The advanced settings (model precision, alpha threshold, edge shrink) apply on change and replace the previous subject and the silhouettes derived from it.

## Other changes

- On macOS, `@opentray/ext-webview` no longer re-asserts the activation policy on every event-drain tick. Each tick, about 60 per second, called `set_activation_policy`, which re-set the application icon and re-rendered the Dock tile, costing a steady 50 to 80 percent of one core per broker even for a window whose content never changed. The policy is now compared against AppKit's current value first ([029d286](https://github.com/jixoai/opentray/commit/029d286e01e933e9961de116ec69428740662ac8)).
- `@opentray/icon` matches the auto background to a solid border ring, so favicons drawn on a white pad keep their backdrop.
- When a glyph needs a CJK character and no CJK font is installed, generation degrades to the neutral terminal mark instead of failing.
- `@opentray/vite-plugin` dropped its sharp dependency.

## Upgrade

```bash
npm i create-opentray@0.23.0
npm i opentray@0.23.0          # the SDK
```

With official extensions, lock the same protocol line: `pnpm add opentray@stable-A-B @opentray/ext-webview@stable-A-B` (protocol-line tags are published by `@opentray/spec`; do not mix them with `latest`).
