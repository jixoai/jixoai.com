jixoai-ui v0.6 (2026-09-25, currently 0.6.0) collects 540 commits since v0.5.1 (2026-09-13): 82 feat / 87 fix / 257 docs, the rest test, chore, refactors and merges. Three threads run through the release: the 110 component doc pages were redone, the style system moved from tailwind to stylex, and the timeline and chart families were rebuilt or fixed. No commit carries a breaking-change mark; upgrading needs no migration.

## Docs site: all 110 component pages redone

Every component page now follows one skeleton: Usage first, then the per-axis mechanism table, Universal props, API, Accessibility, Theming and See Also in that order. Pages used to differ in structure, so readers had to relearn the layout on every page. After the unification, the same kind of information sits in the same place on every page.

The install command moved too. The header's right side of each page's first card now carries a TerminalCard with `npx jixoai-ui add <name>` verbatim; the standalone Install cards are gone, 77 pages in total (71 DocsInstall pages, 5 SectionCard pages and 1 pilot). The command stays copyable and the docs skeleton lint keeps checking it verbatim. The redo passed three external review rounds (4.5 to 8.5 CONDITIONAL GO); the remaining gaps were archived as follow-up work.

## Style system: tailwind out, stylex in

Where styles are written moved from tailwind utility classes to stylex atoms, for the site and the components together. The migration ledger covers 157 files (116 atom modules and 41 sheets). If you install components through `npx jixoai-ui add`, the files you get no longer depend on tailwind utility classes; atom styles ship inside the component files. The migration passed five external review rounds (4.5 to 6.1 to 7.8 to 8.4 to 9.4 GO).

A standing gate watches the residue. verify:tailwindless tracks utility-class identities through an allowlist, currently 2 files with 7 identities and 7 occurrences, each with a written exemption (the boot screen's inline first-paint styles), and the count only goes down.

## chart: font-size fix and self-adaptation

After the eight-axes migration the chart family showed a cluster of symptoms: 42 glyph runs magnified to 96px (7.38x), scrollbars on bars, odd font sizes on some pages. The root cause was the component defaults resolution backfilling donut's outer diameter of 96 into the size slots of bar, sparkline and line. The fix adds one guard at six default-stamping sites: only an explicit number may reach the size slot ([406f12a7](https://github.com/jixoai/ui/commit/406f12a7)).

Self-adaptation is the second fix. The bar chart re-bins its glyph budget against the container's measured capacity, so no width ever produces a scrollbar and the font stays on its density rung; all bars share one start line. Measured in a browser across widths from 360 to 1500: zero overflow, zero scrollbars ([da509b3c](https://github.com/jixoai/ui/commit/da509b3c)).

## timeline: rebuilt to the reui standard

The timeline component was rebuilt: progress renders as a fractional svg-path; connectors lap into the node's own ink band (joint-lap, review GO 9.1/10, [998f36fd](https://github.com/jixoai/ui/commit/998f36fd)); structural strokes share one weight token with the node borders, set once and followed by dots and lines together; the ring dot stays permanently hollow. The regression battery runs 36/36.

## boot-splash: new component

boot-splash is a loading mask. It follows the zero-css-file law: element styles are inline, the sheet vocabulary ships in a head-level inline block, and the font-loading race cannot happen by construction. Five slots (logo / loading / title / subtitle / description), three exits (opacity-out / blur-out / none), a 4-second timeout cap. Installing it is one command.

```bash
npx jixoai-ui add boot-splash
```

## Other changes

- The CLI's `--overwrite` passthrough flags were silently dropped by the item filter before; an item that writes one file twice in a run stalled on the confirmation prompt. They now pass through verbatim to every child process ([b0ace9cb](https://github.com/jixoai/ui/commit/b0ace9cb)).
- input-otp's slot width is now explicit, 40x40 by default, and the density ladder holds in any container; before, the bare input's intrinsic width stretched slots to 167px ([79038f95](https://github.com/jixoai/ui/commit/79038f95)).
- popover's position-area span-suffix inversion is fixed.
- The W2 repair batch covers press-button semantics / the anchor and external rules / dialog closure / alert dismissal / the ItemField icon lane / the ItemSegmented and ItemStepper adapters.
- scroll-run canonicalizes and freezes under print projection, so print output is viewport-independent; verify:print runs 35/35.
- The explicit-props system reached its design freeze: the contract for the unified eight-axis grammar (named / auto / number plus query()) is documented, with the implementation belonging to a later release.
