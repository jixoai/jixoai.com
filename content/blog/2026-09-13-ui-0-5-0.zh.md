jixoai-ui v0.5.0 发布了（2026-09-13）。36 个提交，按前缀统计是 5 个 feat、13 个 fix 与 13 个 docs，其余是 test、chore 与合并；主线只有一个字：spin。加载指示器从此是一个名字——`<Spin spinner="dots">` 或者 `<Spin spinner="blocks-wave">`——而不是一个光标参数。同一条线上还有 vite-plugin 的 spinners 特性、图标基线债的清偿，以及文档站游乐场控件的三件标准化。没有破坏性变更，升级零迁移。

## spin：一个名字，不是光标

参照 ora 的裁定先落下来：纯文字、不包 `[` `]`。然后是名字通道的设计——一个 `spinner` 属性，两条解析车道，**生成的 svg 工件优先，文字目录其次**：

```svelte
<!-- svg 车道：编译期生成的工件名，blocks-wave 是默认 -->
<Spin spinner="blocks-wave" />

<!-- 文字车道：59 名 cli-spinners 目录之一，帧逐字节照搬 -->
<Spin spinner="dots" />
```

名字是编译期联合类型，写错在类型检查时爆红，运行期只剩一次带缓存的警告。尺寸不再自己发明单位：文字通道骑密度标尺的 `var(--jx-text)`，svg 通道骑 `var(--jx-icon)`——和 jixoai.com 站点级排版词汇表同源，正文里的 spinner 与正文同阶，图标位的 loader 与图标同阶。

```spin
{"demos":[{"spinner":"dots"},{"spinner":"arc"},{"spinner":"line"},{"spinner":"blocks-wave"},{"spinner":"tail-spin"}],"caption":"两条车道、一个属性——dots / arc / line 是文字目录名，blocks-wave / tail-spin 是 svg 工件名；这一行是页面里真实转动的组件，不是截图"}
```

无障碍是底座而不是补丁：`role="status"`（自带隐式 aria-live 的等待语义）、`aria-busy` 包裹姿态、`prefers-reduced-motion` 一刀切静态帧。这些不需要调用方写任何一行。

## 文字通道：平铺 CSS 动画引擎

引擎的形状是一次技术裁定：**所有帧一次性平铺渲染，JS 只填动画参数**。DOM 里每帧都在（单格 grid + `white-space: pre`，版面零抖动），CSS 动画负责让该亮的那帧亮——每个参数组合注入一条 `@keyframes`，每帧一个负 `animation-delay` 把自己相位进自己的时隙。

这个形状的收益是结构性的：没有元素进出（帧切换不产生 DOM 变更，GC 与样式重算都安静），没有 JS 时钟（主线程卡顿不影响动画节拍，合成器自己走），DevTools 的 Animations 面板可以逐帧拖拽调试——你能在时间轴上亲眼看到每帧的时隙与残影区间。reduced-motion 是一条媒体查询静态杀，不是运行期分支。

## 残影：lingerType 与手调配对

残影（linger）从「幽灵帧」改名成更诚实的「滞留」：上一帧以线性淡出的方式多活一段，`linger` 以毫秒计，`'auto'` 交给目录。淡出的形状由 `lingerType` 决定：

- `end`（默认）——亮完整拍，尾段线性淡出；
- `start` ——淡入在**交接边界前**完成，下一帧登场时它已经就位（边界前入场，不是边界处开始）；
- `both` ——淡入与淡出两头都有。

`'auto'` 不是公式算出来的，是逐个手调的：每个目录名在策展脚本里携带一对 interval/linger——dots 80/160、dots2 120/0、pipe 120/120、line 160/0、simpleDots 160/160（用 `·` 字形）——引擎负责把这些配对忠实地变成 keyframes 的百分比停点。

```spin
{"demos":[{"spinner":"dots","interval":160,"linger":0},{"spinner":"dots","interval":160,"linger":160},{"spinner":"dots","interval":160,"linger":480},{"spinner":"growVertical"}],"caption":"残影是真实动画：同一个 dots 在 linger 0 / 160 / 480 下的尾巴，以及 growVertical 的手调配对（120/120）"}
```

打磨路上关掉的两个陷阱值得记录：**同百分比停点合并**（`10%{opacity:1}10%{opacity:0}` 在 CSS 里后者吞掉前者，整窗变成线性淡出——离散隐藏必须挂 `steps(1,start)`）与**实心帧法则**（linger ≥ interval 时入场时长必须封顶在 interval/2，否则不透明度只在一个瞬间达峰）。

```spin
{"demos":[{"spinner":"dots"},{"spinner":"dots2"},{"spinner":"line"},{"spinner":"pipe"},{"spinner":"simpleDots"},{"spinner":"arc"},{"spinner":"arrow"},{"spinner":"bounce"},{"spinner":"growVertical"},{"spinner":"toggle3"},{"spinner":"star"}],"caption":"目录画廊：十一个家族各一名代表，帧、名字与节拍都来自真实组件"}
```

## SVG 通道：SMIL 与三个 Chrome 缺陷

svg 车道跑作品自己的 SMIL 动画，组件只管三件事：**每个实例的 id 命名空间**（同一 loader 摆两份，`begin="x.end"` 之类的 syncbase 引用不会跨实例错认）、**切换时 `{#key}` 整体重建**（在常驻 svg 里 innerHTML 换弹药，Chrome 只有 1/12 的概率激活动画）、**动态插入的激活踢**（样式表文本重解析 + `setCurrentTime(0)`，只对 `readyState === 'complete'` 的文档出手，避免水合期把跑着的 loader 拍回起点）。

这条车道是实测喂出来的：94 枚 magecdn loader 全部走过组件路径的像素验证（83 枚直绿，11 枚靠激活踢救回），15 枚依赖外部上下文的动态 loader 带回执排除。颜色全部归一到 `currentColor`——loader 跟随文字色，明暗主题各得其所；本页的演示就是活证据，切换站点主题即可看到同一批 loader 换装。

```spin
{"demos":[{"spinner":"blocks-wave"},{"spinner":"3-dots-bounce"},{"spinner":"bars-scale"},{"spinner":"clock"},{"spinner":"tail-spin"},{"spinner":"spinning-circles"}],"caption":"svg 车道的六枚工件 loader——页面上真实运行的 SMIL，currentColor 跟随主题"}
```

## vite-plugin：spinners 特性

`@jixoai/ui-vite-plugin` 0.4.0 的 spinners 特性与图标库法则逐条对齐：`jixoai({ spinners })` **默认关**，开了才有代码生成；来源支持 `inline` 内联与 `{ file }` 文件引用；RAW 安全闸门照旧把不可信形状挡在门外；产物单写者（`gen:spins` 生成、`verify:spins` 门禁，CI 里手改即红）。

刻意的一个「不做」：**不走 svgo**。`convertShapeToPath` 会把 `<circle>` 改写成 `<path>`，而 SMIL 的 `<animate>` 以形状元素类型定位目标——优化器一跑，动画目标就没了。loader 的 svg 按 RAW 语义进出，只在归一化层做明确清单内的改写（剥 xml 声明、`#fff` → `currentColor`）。

随包发两个现成的 pack 子入口：`@jixoai/ui-vite-plugin/spinners/magecdn`（94 枚，逐枚像素验证过）与 `@jixoai/ui-vite-plugin/spinners/svg-loaders`（SamHerbert 的 12 枚，上游致谢）。

![pack 广度：magecdn 94 枚中撷取的 24 枚 loader 作品（每四枚取一），currentColor 着色，纯效果无正文](/blog-assets/2026-09-13-ui-0-5-0/spinner-packs.png)

```ts
import { magecdnSpinners } from '@jixoai/ui-vite-plugin/spinners/magecdn';
import { svgLoadersSpinners } from '@jixoai/ui-vite-plugin/spinners/svg-loaders';
import { jixoai } from '@jixoai/ui-vite-plugin';

export default defineConfig({
  plugins: [
    jixoai({
      spinners: {
        spinners: {
          ...magecdnSpinners,
          ...svgLoadersSpinners, // 同名按展开顺序覆盖（图标的覆盖法则）
        },
      },
    }),
  ],
});
```
